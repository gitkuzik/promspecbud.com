# Сайт «Промспецбуд Кременчук» — сучасна мультимовна версія (UA / RU / EN / PL)

Сучасний, адаптивний, **багатомовний** офіційний веб-сайт **ТОВ «Промспецбуд» (м. Кременчук)** — провідного підприємства України у сфері спорудження пальових фундаментів.

Сайт зроблено з орієнтацією на **SEO**: кожна мова має власну URL-адресу, зв’язану через `hreflang`, `canonical` та `sitemap.xml` — саме так, як рекомендує Google для мультимовних сайтів.

---

## 🌍 Мови та структура URL

| Мова | Каталог | Приклад |
|---|---|---|
| Українська (основна) | корінь `/` | `https://promspecbud.com/vidy-robit.html` |
| Російська | `/ru/` | `https://promspecbud.com/ru/vidy-robit.html` |
| Англійська | `/en/` | `https://promspecbud.com/en/vidy-robit.html` |
| Польська | `/pl/` | `https://promspecbud.com/pl/vidy-robit.html` |

Кожна сторінка містить:
- `<link rel="canonical">` — на саму себе,
- `<link rel="alternate" hreflang="uk|ru|en|pl">` + `x-default` — на відповідники іншими мовами,
- `<html lang="...">`, локалізовані `<title>` і meta description.

`x-default` вказує на українську версію (основна мова сайту).

Перемикач мови — це **звичайні посилання** (`<a hreflang lang>`) у меню, а не JavaScript: краулери та користувачі потрапляють на потрібну URL-адресу безпосередньо.

## ⚙️ Як це працює (генерація мов)

Переклад зберігається у двох місцях із яких **генеруються** готові статичні сторінки:

1. **Спільний словник** «каркаса» (меню, шапка, підвал, службові елементи) — `js/i18n.js`.
2. **Словники контенту** кожної сторінки — інлайнові `<script type="application/json" id="i18n-page-dict">` у файлах `templates/*.html`.

Генерація виконується у два кроки:

```bash
node tools/extract.js     # збирає переклади → tools/translations.json
python3 tools/build.py    # генерує 4 мови у корінь + /ru/ /en/ /pl/ + sitemap.xml
```

Результат — **36 статичних HTML-файлів**, у яких текст «запечений» безпосередньо (без JS-підміни контенту), тому пошукові боти бачать переклад одразу. Внутрішні посилання та ресурси — **відносні**, тому сайт коректно відкривається і локально (`file://`), і на будь-якому сервері.

> Щоб змінити переклад: редагуйте `templates/*.html` (контент) та `js/i18n.js` (каркас), потім повторіть два кроки вище.

## 🔍 SEO-пакет

- Окрема URL на мову + `hreflang` + `canonical` на кожній сторінці.
- `sitemap.xml` з анотаціями `xhtml:link rel="alternate" hreflang` (36 URL).
- Коректні `<html lang>`, `<title>`, meta description для кожної мови.
- Перемикач мови — звичайні посилання з атрибутами `hreflang`/`lang`.
